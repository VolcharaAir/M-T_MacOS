# M&T для macOS — Марков → Тьюринг

Офлайн-приложение: компиляция нормального алгоритма Маркова в настоящую машину
Тьюринга, отдельное выполнение обеих моделей, визуализация и проверка результатов.

## Скачать и открыть

Установщик **MT-macOS-universal.dmg** публикуется в разделе
[Releases](https://github.com/VolcharaAir/M-T_MacOS/releases). Один пакет для **Intel и Apple Silicon**,
минимум **macOS 12**. Перетащите M&T в «Программы» и откройте.
Flutter, Python и интернет для работы установленного приложения не нужны.

**Статус сборки 4551ba3:** образ собран на Intel Mac. Прошли 88 тестов;
проверены контрольная сумма DMG, подпись и наличие `x86_64` и `arm64` во всех
четырёх нативных бинарниках. Запуск на Apple Silicon ещё предстоит проверить.
Кнопка Code скачивает архив исходников. Тестовый пакет имеет локальную подпись:
может потребоваться разрешение первого запуска в настройках безопасности.

## Собрать на Mac

Нужны Xcode и Flutter 3.50.1 / Dart 3.14. Сначала проверьте среду:

```bash
git clone https://github.com/VolcharaAir/M-T_MacOS.git
cd M-T_MacOS
bash scripts/doctor-macos.sh
```

После настройки среды:

```bash
bash scripts/build-macos.sh
```

Скрипт запускает анализ и тесты, собирает release, проверяет обе архитектуры
каждого нативного бинарника и подпись, создаёт `dist/MT-macOS-universal.dmg`.
Подробные шаги, ограничения и проверка готовой сборки: [docs/MACOS.md](docs/MACOS.md).
