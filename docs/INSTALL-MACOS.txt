M&T — Марков → Тьюринг

1. Перетащите M&T.app на значок Applications («Программы»).
2. Откройте M&T из «Программ».
3. После установки образ можно извлечь.

Поддержка: Intel x86_64 и Apple Silicon arm64; macOS 12 или новее.
Интернет, Flutter и Python для использования приложения не нужны.

Эта тестовая сборка имеет локальную подпись, но не прошла проверку Apple.
Если macOS заблокирует первый запуск, после попытки открытия зайдите в
Системные настройки → Конфиденциальность и безопасность → Всё равно открыть.
Разрешайте запуск только для сборки из доверенного репозитория VolcharaAir/M-T_MacOS.
Отключать защиту macOS целиком не нужно.

При сообщении о повреждённом приложении остановитесь и сообщите разработчику:
не удаляйте атрибуты безопасности и не отключайте Gatekeeper.
